# CI/CD Final Project

## Project Name
Continuous Integration and Continuous Delivery (CI/CD) Final Project

## Description
This project demonstrates the implementation of a CI/CD workflow using GitHub Actions, Tekton, and OpenShift.

The project automates code quality checks, unit testing, image building, and application deployment.

## Objectives
- Create a CI pipeline using GitHub Actions.
- Perform code linting using ESLint.
- Execute unit tests using Jest.
- Create Tekton tasks for linting, unit testing, and building an image.
- Develop an OpenShift CI pipeline using Tekton tasks.
- Deploy the application to the OpenShift cluster.

## Technologies Used
- JavaScript
- GitHub
- GitHub Actions
- ESLint
- Jest
- Tekton
- OpenShift
- Docker

## Project Workflow
1. Push application code to GitHub.
2. GitHub Actions automatically runs linting and unit tests.
3. Tekton executes linting and testing tasks.
4. Build the application container image.
5. Run the OpenShift CI/CD pipeline.
6. Deploy the application to the OpenShift cluster.
